# Abhinay Kumar Nalband — Portfolio

Responsive animated portfolio built with plain HTML, CSS and JavaScript.

## Run locally
1. Open this folder in VS Code.
2. Open `index.html`.
3. Use the Live Server extension, or double-click `index.html` to open it in a browser.

## Included
- Dark + light themes (saved in localStorage)
- Animated hero portrait with mouse tilt/parallax
- Four Featured Work cards
- User-provided e-commerce image
- Responsive desktop/mobile layout
- Scroll reveal and hover interactions

No build step or package install is required.
